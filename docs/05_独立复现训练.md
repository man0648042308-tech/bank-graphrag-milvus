# 独立复现训练：从“看懂”到“写出”

AI 已经把完整实现和测试准备好，但你要达到独立复现，必须产生自己的证据。不要一上来闭卷写整个项目，按 6 关推进。

## 第 1 关：10 分钟硬规则

打开新文件 `learning/closed_book/rebuild_filter.py`，不要复制源码，写出：

```text
输入：一个客户字典、一个产品字典
处理：产品有效、产品风险不高于客户、起购金额不高于可用金额
输出：True 或 False
```

验收：自己构造一个通过和一个不通过例子；故意把金额改成字符串，读出错误类型、文件和行号，再修复。

## 第 2 关：20 分钟 RRF

从空白写函数：输入多个产品 ID 排名列表，按 `1/(60+名次)` 累加并降序返回。先只处理 ID，不写类。

口述：为什么不能直接把余弦、BM25 和购买次数相加？

## 第 3 关：25 分钟三节点 LangGraph

只搭：

```text
START -> retrieve -> filter -> explain -> END
```

每个节点先返回固定字典。验收重点是 State、Node、Edge、compile、invoke，不要求连数据库。

## 第 4 关：30 分钟 Cypher

不看答案写出：

1. 查询 C001 买过的产品；
2. 统计每个客户购买数量；
3. 查询 C001 两跳内关联的产品。

每条都说明变量名可改、标签/关系类型为什么不能随便改。

## 第 5 关：30 分钟安全 NL 查询

画出并口述：

```text
自然语言 -> 生成 -> 校验 -> 白名单 -> 参数化 -> LIMIT -> 只读执行
```

然后手写 3 个拒绝测试：`DELETE`、未授权表、两条语句。

## 第 6 关：60 分钟最小项目闭卷

只允许看任务合同，不看源码：

- 2 个客户、3 个产品；
- 图召回 + 向量召回；
- RRF；
- 风险/金额过滤；
- 3 个 pytest；
- 主程序打印推荐和解释。

通过线：

- 80 分：可运行、测试通过、能修一个自己制造的错误。
- 90 分：再加入 LangGraph、参数化查询和 README。
- 不通过：复制了完整实现但解释不出输入、处理、输出和边界。

## 六段晚间训练模板

| 时间 | 具体产物 |
|---|---|
| 19:00–19:30 | 按操作手册跑通一个最小链路，记录命令与输出 |
| 19:30–20:20 | 学本日唯一概念，手写不超过 20 行最小例子 |
| 20:30–21:30 | 跟复现指南实现并改一个条件 |
| 21:40–22:40 | 合上资料，在 `learning/closed_book` 重写 |
| 22:40–23:10 | 跑测试、制造一个错误、写错误记录 |
| 23:10–23:25 | 无稿口述输入、处理、输出、错误、岗位价值 |

## 口述验收 8 题

1. `RecommendationState` 在节点之间传什么？
2. 图召回、社区召回、向量召回各解决什么盲区？
3. RRF 为什么用名次？
4. 为什么 P003 分数高也不能推荐给 C001？
5. `stream` 与 `write` 模式有什么区别？
6. Louvain 的 `communityId` 能不能当客户等级？
7. 模型生成 SQL 后为什么不能立刻执行？
8. Milvus 插入后为什么显式 `flush()`？

答题标准：不用背定义，必须能用本项目数据举例。
